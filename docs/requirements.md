# 제품 요구사항

## 목적

종이로 된 영어 학습 자료를 디지털로 정돈해 보관하고, 자료의 내용으로 복습할 수 있게 한다.

## 결정된 방향

- **회차형 읽기와 개인 학습 기록:** 수업 화면은 사진을 전부 펼치지 않고 각 자료 묶음을 `1회차`, `2회차`처럼 들어가는 카드로 보여 준다. 회차는 **묶음 전체 AI 변환이 성공한 뒤** 하나의 연속된 흰 HTML 본문으로 읽는다. 쪽별 카드나 별도 쪽 메모 화면으로 끊지 않는다. 소유자는 아이패드에서 회차를 읽다가 메모 추가를 누르고 **본문의 원하는 위치를 찍어**, 그 자리와 연결된 키보드 메모 또는 Apple Pencil 필기를 여러 개 남기고 수정한다. 변환 전에는 사진 원본과 묶음 변환 버튼만 보여 주며 위치 메모를 열지 않는다. 메모와 필기 이미지는 소유자만 열람한다. 필기는 명시적으로 글자 인식을 실행하고 결과를 직접 고칠 수 있어야 한다. 저장한 텍스트 메모와 확인한 필기 인식 결과를 같은 수업의 문제 생성 및 이후 시험의 부족한 부분 분석에 활용한다. 회차별로 메모를 바탕으로 복습 포인트를 요청할 수도 있다. 메모만으로 확정적인 오답이나 실력을 단정하지 않는다.

- **업로드와 AI 변환은 별도 작업이다.** 업로드 직후에는 순서대로 보관한 원본 사진을 보여 준다. 소유자가 묶음별 변환 버튼을 누른 뒤에만 ChatGPT Plus 이용량으로 정리한다. 변환 도중 한 쪽이라도 실패하거나 이용량 제한에 걸리면 그 묶음의 정리본과 사용량 기록을 전혀 바꾸지 않는다. 이전 정리본이 있으면 그대로 유지한다. 재시도는 소유자가 직접 시작한다.
- **원본의 순서와 시각적 성격을 우선한다.** 사진 및 사진 속 인쇄문·필기의 위에서 아래, 왼쪽에서 오른쪽 순서를 유지한다. AI가 임의로 내용을 주제별 재배열하거나 원본에 없는 색, 강조, 문제, 예시를 추가하지 않는다. 정리본은 흰 바탕의 검정 글씨로 표시하고 필기 해설은 펼쳐 보는 보조 설명으로 둔다. 원본 사진을 언제든 확인할 수 있어야 한다. 자동 필사가 종이의 모든 칸·선·글꼴·정확한 위치까지 재현한다고 보장하지 않으며 소유자가 원본과 대조해 수정한다.

- 휴대폰과 아이패드의 웹브라우저에서 모두 사용할 수 있는 웹앱으로 시작한다. 두 기기 모두에서 로그인, 사진 업로드, 주차별 열람, 내용 수정, 복습 문제와 시험 점검, 댓글 작성이 가능해야 한다. 컴퓨터 사용을 필수로 요구하지 않는다.
- 사진 원본을 보관하고, AI로 내용과 필기를 최대한 그대로 옮겨 적은 뒤 사용자가 확인하고 수정한다. 현재 구현은 OpenAI API를 선택 기능으로 사용한다.
- 정리본은 HTML 기반으로 화면에서 읽고 수정할 수 있게 만들고, 인쇄용 화면을 통해 PDF 저장을 지원하는 방향으로 진행한다.
- 문제에 대한 사용자 피드백을 저장해 문제 수정 또는 다음 문제 생성에 반영한다. 반영 방식의 세부 사항은 아직 정하지 않았다.
- 복습 문제 풀이마다 작성 답·기준 답·맞음·틀림·미확인·어려움을 시도별로 저장한다. 소유자 전용 학습 기록에서 누적 결과와 다시 볼 문제를 확인하고, 확인된 오답과 어려운 문항을 다음 문제 생성에 반영한다. 시험 업로드와 문항별 점검 결과도 계속 보존한다.
- 같은 주차에는 월요일·수요일처럼 수업을 나중에 계속 추가할 수 있고, 이미 올린 자료의 내용과 소속 주차를 수정할 수 있다.
- 한 수업 안에서도 호치케스로 묶인 학습지 단위를 따로 보관한다. 새 수업 작성 화면에서 `묶음 추가`로 `did` 2장과 `when` 3장을 각각 지정하고 **한 번의 저장으로 함께 업로드**할 수 있어야 한다. 묶음마다 제목·사진 순서와 종이에 적힌 필기를 유지한다. 저장 뒤에도 묶음과 사진을 추가하고, 묶음 이름·순서 및 사진의 소속 묶음을 수정할 수 있다. 사진을 한 장씩 삭제하거나 묶음의 사진을 전부 비운 뒤 다시 올릴 수 있다. 화면과 HTML/PDF 출력에서도 경계를 유지한다. 묶음별 **「이 묶음의 내용과 필기」 수동 입력란은 두지 않는다**.
- 기본 열람 화면은 사진의 A4 보정본이 아니라, 사진의 인쇄 내용과 필기를 AI가 읽고 순서·관계를 해석해 HTML 텍스트로 다시 구성한 연속 학습 페이지여야 한다. 예문·문제·표의 관계와 손글씨 원문을 보존하고, 필기가 무엇을 가리키고 왜 적혔는지를 별도 해설로 제시한다. 불확실한 판독은 원본 확인 필요로 표시하고 소유자가 쪽별 블록을 수정할 수 있어야 한다. 사진은 근거로 펼쳐 보고 비교한다. API 호출은 소유자 동의 전까지 꺼 둔다.
- 한 묶음이 9장 이상이어도 1쪽부터 마지막 쪽까지 순서가 확실히 보존되어야 한다. 업로드 전에 사진의 표시 순서를 확인·수정하거나 한 장씩 삭제할 수 있고 저장 뒤에도 순서를 고칠 수 있어야 한다. 아이패드에서는 묶음 전체를 세로로 계속 스크롤하며 읽는다. 휴대폰에서도 같은 흐름을 제공한다. 각 페이지는 원본을 보관하면서 종이 경계·기울기·원근 등을 확인 가능한 범위에서 보정하고, 잘림 없이 A4 비율의 정돈된 읽기 화면과 A4 PDF로 보여준다. 필기와 문제 칸을 임의로 재배치하거나 삭제하지 않는다. 자동 보정이 불확실하면 원본과 비교해 사용자가 보정 결과를 바꿀 수 있어야 한다.
- 각 수업과 시험에 강사를 지정하고 나중에 바꿀 수 있다. 같은 주차의 자료를 강사별로 묶어서 보여준다. 같은 강사의 월·수 수업은 한 묶음으로, 다른 강사의 수업은 별도 묶음으로 본다.
- 강사마다 문제 유형·스타일을 설정한다. 향후 자동 문제 생성은 해당 강사의 스타일, 문제 피드백, 오답·어려운 시험 문항을 우선 사용해 다른 강사의 스타일과 섞이지 않게 한다.
- 자료 업로드와 자료·문제 수정은 소유자 한 명만 한다. 소유자는 받은 피드백을 보고 Codex와 함께 결과를 수정·개선할 수 있다.
- 로그인하지 않아도 사이트의 모든 주차·자료·원본 사진·시험 답안·문제·단어장을 열람할 수 있다. 댓글은 로그인한 사람만 남길 수 있다. 초대받은 사람은 댓글을 쓸 수 있지만 자료와 문제는 직접 수정할 수 없다.
- 홈은 로그인 없이도 `1주차`, `2주차`, `3주차`처럼 주차별 입구를 보여준다. 한 주에 수업이 여러 개 들어갈 수 있으며 개수는 고정하지 않는다.
- 수업과 시험은 다른 종류의 자료다. 수업 페이지는 촬영 원본과 필기를 최대한 그대로 보존하고, 연습문제는 별도 페이지에서 제공한다.
- 다음 주에 이전 주 학습 내용을 시험 본다. 시험지를 올리면 원본과 답안을 최대한 그대로 보존하고, 시험 문항별로 맞음·틀림과 어려웠음 여부를 확인·수정할 수 있다. 확인된 결과를 바탕으로 부족한 부분을 분석한다.
- 모르는 영어 단어와 문장을 수업·시험 자료에서 단어장으로 저장하거나 직접 추가한다. 한국어 뜻을 입력·수정하고 번역 기능으로 뜻을 채울 수 있어야 한다. 저장한 표현은 한곳에서 검색하고 출처 자료로 돌아갈 수 있어야 한다.
- 서버와 저장 공간을 무료로 배포할 수 있어야 한다. 무료 사용량 제한과 AI API 비용은 별도로 명확히 안내한다.
- ChatGPT Plus와 현재 사이트의 OpenAI API 키 요금은 별개다. 사용자가 추가 API 과금에 난색을 보여 유료 API 자동 기능을 기본 중지한다. 수동 필사·문제 작성과 DeepL 번역은 유지한다. Plus 이용량을 앱에 연결하는 공식 Sign in with ChatGPT 경로는 지원 범위와 원격 배포 적합성을 별도로 검토하기 전까지 사용 가능하다고 가정하지 않는다.
- 2026-10-10 공식 문서 재확인: 적격 Plus 사용자는 Sign in with ChatGPT에서 **별도 이용량 공유 동의**를 하면 지원 앱의 AI 요청에 Plus 이용량을 사용할 수 있다. 이미지 입력도 지원된다. 오픈소스 앱을 개인 VM에서 실행하는 절차가 있지만, 유료 앱 또는 원격으로 제공하는 앱은 별도 신청을 안내한다. OAuth 동의와 실제 요청 성공을 확인하기 전에는 API 키를 Plus 이용량으로 대체했다고 주장하거나 OAuth 토큰을 임의로 재사용하지 않는다. 당장 추가 API 요금 없이 가능한 방법은 Plus에 포함된 Codex 대화/IDE에서 소유자가 사진 정리를 요청하고 그 결과를 사이트에 반영하는 수동 흐름이다. 이는 사이트 업로드 직후 자동 변환과는 다르며 Plus 사용량 제한을 따른다.
- 2026-10-10 소유자가 앱 코드 공개에 동의해 MIT 라이선스의 공개 GitHub 저장소 `oscar2272/page-by-page-english`를 만들었다. 사진·DB·키·백업은 Git에서 제외한다. 공식 오픈소스용 OAuth는 소유자 컴퓨터의 `127.0.0.1` 콜백으로 최초 동의를 받고, VM에는 보호된 자격 정보를 별도로 전달해야 한다. 로컬 동의 및 서버 연동의 실제 성공 여부는 확인 중이며, 기존 유료 API 자동 기능은 계속 중지한다.

## 사용자 흐름

1. 영어 학습지를 사진으로 찍어 소프트웨어에 올린다. 한 자료에 사진 여러 장이 필요할 수도 있다.
2. 사진의 내용과 필기를 순서대로 옮겨 적는다. 읽기 어려운 부분을 표시하고 사용자가 확인해 고칠 수 있어야 한다.
3. HTML 기반 정리본을 열람하고, PDF로도 저장할 수 있다.
4. 자료를 번호가 있는 주차에 넣고 주차별로 찾는다. 각 자료의 소속 주차는 사용자가 수정할 수 있어야 한다.
5. 자료 내용을 바탕으로 복습 질문을 만든다. 사용자가 문제의 형태와 품질에 피드백을 주면 이후 생성 결과를 개선할 수 있어야 한다.
6. 누구나 모든 자료와 문제를 읽을 수 있다. 로그인한 사용자는 댓글을 남기고 소유자는 이를 자료나 문제 수정에 활용한다.
7. 홈에서 주차를 선택해 그 주의 수업 여러 개와 시험을 본다. 수업을 열어 원본·필기를 확인하고 별도의 연습문제 페이지로 이동한다.
8. 다음 주의 시험 자료를 올릴 때 시험 대상인 이전 주를 지정한다. 시험 문항별 정오와 어려움 표시를 검토한 뒤 부족한 부분을 확인한다.
9. 공부하다 모르는 단어·문장을 단어장에 저장하고, 한국어 뜻을 직접 입력하거나 번역한 뒤 전체 단어장에서 다시 찾는다.

## 반드시 유지할 요구사항

- **휴대폰·아이패드 웹 지원:** 두 기기의 화면 크기와 세로·가로 방향에서 주요 화면과 입력 폼을 사용할 수 있어야 한다. 특정 작업을 컴퓨터에서만 하도록 제한하지 않는다.
- **원본과 정리본의 연결:** 어떤 사진에서 정리본이 만들어졌는지 확인할 수 있어야 한다. 인식 오류를 수정할 수 있도록 원본을 보존하는 방향으로 설계한다.
- **원본에 충실한 필사본:** 사진을 단순히 PDF에 넣는 것만으로 끝내지 않는다. 텍스트와 필기를 순서대로 옮겨 학습 자료로 다시 볼 수 있어야 한다.
- **수정 가능한 주차:** 주차를 필요한 만큼 추가하고, 각 자료의 소속 주차를 바꿀 수 있어야 한다.
- **강사별 구분:** 강사를 추가·수정하고 수업과 시험에 연결한다. 같은 주차 안에서 강사별 자료를 분리해 보며 강사별 문제 스타일과 피드백을 독립적으로 관리한다.
- **수업 내 자료 묶음:** 한 수업의 여러 종이 묶음을 제목과 장수로 구분하고 묶음별 원본·필기를 함께 보여준다. 묶음을 나중에 추가하고 사진을 다른 묶음으로 옮기거나 순서를 바꾸고, 한 장 또는 묶음의 사진 전체를 삭제한 뒤 다시 올릴 수 있어야 한다. 별도 묶음 필기 입력은 요구하지 않는다. 호치케스 자체의 자동 인식은 필수 요건이 아니며 분류는 소유자가 확인·수정한다.
- **긴 묶음 읽기:** 9장 이상의 묶음도 한 흐름으로 올리고 저장 전후에 순서를 검토·수정할 수 있어야 한다. 아이패드에서 HTML로 재구성한 내용을 웹툰처럼 아래로 이어 읽고, 같은 내용의 PDF와 각 쪽의 촬영 원본을 확인할 수 있어야 한다. 변환 전 쪽은 원본 사진을 표시한다.
- **피드백 가능한 문제 생성:** 문제를 만든 뒤 사용자가 문제 유형, 난이도, 표현, 정답의 정확성 등에 피드백을 남기고 수정하거나 다시 생성할 수 있어야 한다. 구체적인 피드백 UI와 반영 방식은 추후 결정한다.
- **공개 열람과 수정 권한 분리:** 비로그인 사용자도 모든 주차·자료·원본 사진·시험 답안·문제·단어장을 열람할 수 있다. 댓글은 로그인한 사용자만 작성한다. 업로드·정리본 수정·문제 수정·초대 관리는 소유자만 한다. 개인 학습 기록과 계정·설정은 공개하지 않는다.
- **수업 기록의 충실도:** AI는 인쇄 원문과 손글씨 원문을 구별해 옮기고, 필기의 의도와 대상 문장을 별도 해설로 제시한다. 원본에 없는 표현을 보태거나 불명확한 필기를 단정하지 않는다. 촬영 원본은 검수와 재변환의 근거이므로 변환 직후 폐기하지 않는다. 검수가 끝난 뒤 저장 공간을 줄일 압축·보관 방식을 별도로 결정한다.
- **시험의 연결과 검토:** 시험은 시험이 놓인 주차와 시험 대상 주차를 구분한다. AI의 정오 제안은 확정 점수가 아니며, 소유자가 문항별 맞음·틀림과 어려움 표시를 고칠 수 있다.
- **단어장과 번역:** 단어와 문장을 구분해 원문·한국어 뜻·메모·출처 자료를 저장한다. 번역 결과는 사용자가 확인하고 수정할 수 있어야 한다. 비로그인 사용자도 단어장을 볼 수 있지만 추가·수정은 소유자만 한다.

## 첫 구현의 임시 선택

현재 코드는 Flask와 SQLite를 사용한다. 로컬에서는 사진과 DB를 `instance/`에 저장하고, Docker Compose 배포에서는 영구 볼륨에 저장한다. 소유자가 아이디와 비밀번호를 만들고, 초대 계정을 생성해 임시 비밀번호를 직접 전달한다. AI 연결은 API 키가 있을 때 사용하며, 키가 없어도 내용·문제·단어장 뜻을 직접 입력할 수 있다. 단어장의 자동 번역은 DeepL API 키를 우선 사용하고, 키가 없고 OpenAI 키가 있으면 OpenAI를 사용한다. 로컬 키는 Git 제외 파일 `.env`에 설정할 수 있다. DeepL의 현재 Developer 신청 화면은 무료 번역량을 일회성 100만 자로 표시하며 카드·주소 입력과 이메일 인증을 요구한다. 가입 조건은 실제 신청 화면에서 확인한다. 무료 배포용으로 Oracle Cloud Always Free VM, Docker Compose, Caddy를 사용한다. 현재 서버와 DNS 연결 상태는 위 배포 상태를 따른다.

## 2026-10-10 웹툰 본문 직접 필기

AI 변환이 묶음 전체에서 성공한 뒤에만 회차 HTML 위에 투명한 필기층과 도구를 표시한다. Apple Pencil 필기는 별도 메모판이나 원본 사진 위가 아니라 이어 읽는 영어 본문 위의 원하는 위치에 직접 남긴다. 한 손가락으로는 스크롤하고 Pencil/마우스로 쓰며, 지우개·되돌리기·읽기 모드를 제공한다. 쪽별 벡터 획을 SQLite에 자동 저장하고 재방문 시 다시 그린다. 키보드 위치 메모는 별개로 유지한다. 필기는 소유자에게만 보이며, 명시적으로 AI 글자 인식을 실행한 뒤 교정한 내용이 문제 생성과 복습 분석에 들어간다. 실제 Apple Pencil 기기에서의 입력감과 화면 크기 변경 후 필기 정렬은 아이패드에서 최종 확인이 필요하다.

묶음 변환 도중 Plus 스트림이 미완료되거나 일시적으로 연결이 끊기면 해당 쪽을 최대 두 번 재시도한다. 모든 쪽이 성공할 때까지 정리본과 사용 기록은 반영하지 않는다. 2026-10-10 첫 9장 변환 시도는 5번째 쪽의 미완료 스트림으로 실패했으며, 이전 1장 정리본과 원본 9장은 유지됐다.

같은 날 재시도에서는 9장 모두 성공하여 총 205개 HTML 블록이 순서대로 공개 회차에 반영됐다. 브라우저에서 연속 본문과 Pencil 도구의 필기층 활성화/읽기 모드 복귀를 확인했다. 원본 사진과 대조한 OCR 정밀 검수 및 실제 Apple Pencil 필기감 검증은 아직 남아 있다.

실제 배포 회차에서 시험용 마우스 획을 본문 위에 그리고 저장, 새로고침 후 복원, 되돌리기로 0획 복귀까지 확인했다. 시험 획은 남기지 않았다.

## 2026-10-10 원본 디자인 보존 정정

'흰색 화면'은 앱이 임의의 화려한 테마를 더하지 않는다는 뜻이다. 종이 자체에 존재하는 옅은 회색 설명 상자, 강조, 두 열 비교표의 테두리와 행·열, 예문 목록, 제목 계층, 아이콘과 인쇄 색은 변환된 HTML에서도 최대한 재현해야 한다. 예를 들어 `Make = you build it`과 그 아래 설명은 원본처럼 같은 회색 상자 안에 보여야 한다. AI가 없는 색을 만들어내거나 표를 평문으로 펼쳐서는 안 된다. 기존 변환 결과는 원문과 필기 위치를 유지하면서 화면 렌더링 단계에서 원본 디자인을 복원한다. 이후 AI 변환은 각 블록의 외형 정보를 별도로 저장하고 소유자가 원본과 비교해 수정할 수 있어야 한다. 사진과 동일한 픽셀 단위 재현을 주장하지 않으며, 불확실한 서식은 원본 비교로 확인한다.
